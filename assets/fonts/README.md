# 本地字体

- `Oswald.woff2`：参考站公开使用的 Oswald Medium 字体文件；来源 `https://web.hycdn.cn/arknights/official/_next/static/media/Oswald-Medium.99836e81.woff2`。Oswald 项目采用 SIL Open Font License，见 `Oswald-OFL.txt`，上游 `https://github.com/googlefonts/OswaldFont`。
- `Montserrat.ttf`：Google Fonts 分发的 Montserrat 可变字体，来源 `https://github.com/google/fonts/tree/main/ofl/montserrat`，经 jsDelivr 的 GitHub 镜像取得；许可见 `Montserrat-OFL.txt`。

只在网页内本地加载，没有安装系统字体或修改全局配置。没有复制参考站的专有中文字库或 Novecento 字体。
